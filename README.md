# DesignLaboratory2026
Microcontroller-based PWM controller for a 12 V server fan with OPC server integration. Developed for the Design Laboratory course.
## Postępy prac
###Tydzień 9–15 listopada 2026 r.
Opracowano wstępną koncepcję układu chłodzenia płytki PM12, uwzględniając rozmieszczenie wentylatorów i czujników oraz sposób sterowania obrotami. Dobrano główne elementy prototypu oraz przygotowano schemat połączeń i orientacyjny kosztorys.
